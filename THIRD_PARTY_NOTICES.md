titulares, incluidos Rockstar Games / Take-Two. No se ha establecido una licencia abierta
de redistribución para esos recursos. MIT del código no se extiende a ellos.

Los recursos extraídos, capturas y DB no se versionan. La UI conserva procedencia y atribuciones
cuando existen. No se han publicado assets ni un sitio público.
Fixtures de tests y geometría de demo son sintéticas, creadas para este proyecto.
